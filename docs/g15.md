# Dell G15

O G15 possui dois papéis.

```text
Windows
└── Codex + ai-memory.exe + hooks
    cliente local

WSL2 Debian
└── Docker Compose
    └── ai-memory
        servidor central
```

## Servidor

Diretório:

```text
~/deploy/ai-memory
```

Arquivos:

```text
~/deploy/ai-memory/docker-compose.yml
~/deploy/ai-memory/.env
```

Token:

```text
~/.config/ai-memory/auth-token
```

O token e o `.env` não devem ser versionados.

## Dados

Volume:

```text
ai-memory-data
```

Dentro do container:

```text
/data/wiki
/data/db/memory.sqlite
```

No WSL:

```text
/var/lib/docker/volumes/ai-memory-data/_data
```

## Verificar servidor

```bash
cd ~/deploy/ai-memory

docker compose ps
docker exec ai-memory ai-memory --version
docker logs --tail 50 ai-memory
```

## Atualizar servidor

No WSL:

```bash
update-ai-memory.sh
```

## Atualizar cliente Windows

No PowerShell:

```powershell
ai-memory upgrade
```

## Backup

Script real:

```text
~/bin/backup-ai-memory.sh
```

Cópia versionada:

```text
scripts/backup-ai-memory.sh
```

Cron:

```cron
0 * * * * /home/diasgarcia/bin/backup-ai-memory.sh >> /home/diasgarcia/backups/ai-memory-backup.log 2>&1
```

O cron executa enquanto o WSL estiver ativo.
